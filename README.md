# Sneakers Collection

A Nuxt application for a personal sneaker collection.

## Stack

- Nuxt 4
- Vue 3
- Tailwind CSS 4
- TypeScript
- Nuxt Color Mode

## Development

Install dependencies:

```bash
npm ci
```

Start the development server:

```bash
npm run dev
```

Check types and create a production build:

```bash
npm run typecheck
npm run build
```
